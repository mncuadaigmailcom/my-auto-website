ℹ️ Gói tải về là một PWA (Progressive Web App) — gồm manifest, icon bạn chọn và service worker để chạy offline. Mở icon "index.html" trong thư mục qua trình duyệt rồi:
• Android/Windows (Chrome/Edge): bấm "Cài đặt ứng dụng" trên thanh địa chỉ để cài như app thật.
• iOS (Safari): bấm nút Chia sẻ → "Thêm vào MH chính".
Lưu ý: đây không phải file .apk/.ipa/.exe biên dịch sẵn — việc build file cài đặt gốc cho từng nền tảng cần công cụ chuyên dụng (Android Studio, Xcode, v.v.) ngoài trình duyệt.
